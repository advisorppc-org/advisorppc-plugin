# Support

## Documentation

- Product documentation: https://advisorppc.com/docs
- First-run and troubleshooting: the `getting-connected` skill bundled with
  this plugin.

## Contact

- Email: **contact@advisorppc.com**
- Plans and billing questions: include the email address of the account you
  connected with.

## Reporting a problem

When something misbehaves, include:

1. What you asked Claude to do, and what happened instead.
2. The plan you are on (free or paid).
3. Approximate time (with timezone) so we can correlate server logs.

Bug reports about the plugin manifest or skills may also be filed as GitHub
issues on this repository. Security reports must follow
[SECURITY.md](SECURITY.md) instead, never a public issue.
