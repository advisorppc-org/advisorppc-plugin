PASS if the report gives paid (Google Ads), site (GA4) and organic (Search Console) figures under separate headings, uses the tool figures (for example 4,180.55 EUR Ads cost and 2,950 organic users from google / organic), and never adds conversions from different platforms into one total.
FAIL if it sums Ads, GA4 and Search Console numbers together, uses US dollars, or invents figures not in the tool results.
